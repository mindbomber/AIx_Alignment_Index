# Security Policy

Report suspected vulnerabilities privately through GitHub Security Advisories
for this repository. Do not open a public issue containing exploit details,
credentials, personal data, or tenant data.

Include the affected version, reproduction steps, impact, and any proposed
mitigation. Maintainers should acknowledge a report within three business days,
provide a severity assessment within seven business days, and coordinate
disclosure after a fix is available.

Only the latest minor release receives routine security fixes while the project
is pre-1.0. Never use example credentials or development secrets in a shared
environment.
