# Support And Escalation

Use GitHub Discussions for usage questions and GitHub Issues for reproducible
bugs and feature requests. Include the AIx version, deployment type, sanitized
logs, and reproduction steps.

Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.
Production operators should define an internal on-call owner and escalation
contacts before deployment; the open-source project does not provide a hosted
service SLA.
